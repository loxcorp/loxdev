# Changelog

All notable changes to this project are documented here. This project follows
[semantic versioning](https://semver.org).

## 0.4.0

- Restructured into a modular toolkit: CLI, library (`require("loxcorp")`), and MCP server.
- Added Lox-native commands and tools: `launches`, `network`, `lox`, `agent`, plus decoded mandates.
- Added the `contracts` reference command and the `lox` binary alias.
- MCP server now exposes 21 Robinhood Chain + Lox tools over stdio.

## 0.3.1

- Initial public CLI with live chain reads and a first MCP server (18 tools).
